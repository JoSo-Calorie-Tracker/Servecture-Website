# Servecture Website

Static website ready for GitHub Pages.

## Publish on GitHub Pages
1. Create a GitHub repository.
2. Upload all files and the `assets` folder from this project to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select your main branch and `/ (root)`, then save.
6. Add your custom domain in GitHub Pages when `servecture.com` is ready.

## Files
- `index.html` — commercial landing page
- `privacy.html` — privacy policy
- `terms.html` — terms and conditions
- `styles.css` — responsive styling
- `assets/servecture-logo.png` — Servecture brand logo
- `.nojekyll` — serves the site directly as static files
